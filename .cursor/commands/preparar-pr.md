# Preparar PR

1. Usá el subagente `tester` sobre las carpetas modificadas.
2. Usá el subagente `revisor` sobre el diff contra `develop`.
3. Si hay fallas graves, listalas y detenete.
4. Si todo está bien, redactá el título y la descripción del PR con `.github/pull_request_template.md` y mostrámelos antes de crearlo.
